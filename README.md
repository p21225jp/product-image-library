# 素材柜 · 内网产品图片库

面向内部产品素材管理的本地应用：浏览器上传和预览，按产品 SKU、名称、别名与图片属性搜索；本地 MCP 工具可将原图取到工作目录。

## 已实现

- 首次在服务器本机创建管理员；密码使用 scrypt 哈希，8 小时登录会话。
- 产品 SKU 按文本保存，保留前导零；支持名称、单选分类、别名；分类选项可在新建或编辑产品时创建，并自动选中。
- JPG / PNG / WebP 多文件顺序上传；每张 25 MB、4000 万像素以内，每批前台最多 30 张。
- 原文件原样保留；另生成 WebP 缩略图。自动识别真实透明像素。
- 同一产品内按 SHA-256 提示重复；允许同一张素材关联不同产品。
- 类型（产品图 / 场景图 / 其他）、角度（正面 / 背面 / 侧面 / 俯视 / 仰视 / 其他）、背景（透明 / 其他）、产品分类筛选；分页；待整理图片关联产品。
- 单张原图下载、批量 ZIP 下载（每次最多 100 张、500 MB）。
- 回收站与恢复；回收站内可勾选后「永久删除」，确认后同时删除原文件与缩略图，不可恢复。
- 产品别名与图片标签自动 NFKC 规范、去重并保持输入顺序。
- 启动时清理上次异常退出遗留的临时文件。
- 三种角色，每人一个账号（管理员在网页「账号管理」中创建）：
  - **管理员**：全部权限，含账号管理、回收站、操作记录。
  - **内部账号**（staff）：浏览、搜索、下载、**上传图片**，可新建和编辑产品、分类及图片属性，并可**创建令牌**交给 AI 工具；**不能删除任何内容**（图片、分类、产品都不行），也不能管理账号、进入回收站或查看操作记录。
  - **外部账号**（external）：只能浏览、搜索、下载；不能上传、修改、删除，**不能创建或查看任何令牌**。
- 删除账号会立即作废其登录会话，并同时删除该账号创建的令牌；重置密码同样会强制该账号重新登录。
- 可按账号创建和撤销的 API 令牌（记录归属人与最后使用时间）；操作记录。
- 本地 stdio MCP 取图工具：`search_products`、`search_images`、`get_image_info`、`export_images`。

## 启动

部署到公司常开服务器、通过内网或公司 VPN 使用时，请先阅读 [公司服务器部署交接](deploy/README.md)。内含 Windows / Linux 启动模板、HTTPS 代理配置、迁移步骤与 IT 需要确认的信息。

此电脑已安装项目独立依赖。双击 `start.cmd`，或在项目目录运行：

```powershell
.\start.ps1
```

服务默认监听 `0.0.0.0:8750`，可通过本机及内网访问。只允许本机访问时：

```powershell
.\start.ps1 -LocalOnly
```

1. 在运行服务的电脑打开 `http://127.0.0.1:8750`。
2. 自己创建管理员账号及至少 10 位的独立密码；没有默认密码。
3. 新建产品，或先上传到「待整理」再关联产品。
4. 在侧栏「账号管理」中按人创建账号：内部同事选「内部账号」，客户选「外部账号」（密码至少 10 位），页面会显示并支持复制访问地址。
5. 把地址（例如 `http://192.168.x.x:8750`）和本人的账号密码发给对方。内部同事可上传并自行创建令牌；外部客户只能浏览和下载。

同事打不开地址时，先确认 Windows 防火墙已放行 TCP 8750。管理员 PowerShell 示例（仅放行内网与本机子网）：

```powershell
New-NetFirewallRule -DisplayName "ProductImageLibrary 8750" -Direction Inbound -Protocol TCP `
  -LocalPort 8750 -Action Allow -RemoteAddress LocalSubnet
```

如果 Wi-Fi 被 Windows 识别为「公用网络」，还需设置 `-Profile Any`，或把该网络改为专用网络。防火墙规则不会自动修改。

### 换网络（Wi-Fi ↔ 有线）后怎么办

插上网线后，服务器会拿到公司 DHCP 分配的另一个内网 IP，同事要用的地址也随之变化。例如从 Wi-Fi 的 `10.10.40.x` 变成有线的 `10.68.73.x`。

1. 服务本身不用重开：`serve.py` 监听 `0.0.0.0:8750`，新增网卡会自动生效。
2. 打开网页「账号管理」，地址栏显示的是服务端**当前启用的网卡**地址，刷新页面即可看到新地址并重新复制给同事。
3. 公司网络一般是域环境（`DomainAuthenticated`）。域配置文件的 Windows 防火墙如果由组策略下发（`LocalFirewallRules: N/A (GPO-store only)`），本机自己新建的规则**不会生效**；而且公司通常还会部署终端防护软件（例如 Trend Micro Apex One）自带防火墙。这种情况需要 IT 在组策略或终端防护策略里放行 TCP 8750，用户自己改不了。
4. 公司网络常见「同一交换机/无线下的终端互通受限」：如果同事和服务器不在同一网段，需要 IT 确认路由与访问控制策略。

首次安装到其他 Windows 电脑，需要 Python 3.10+。`start.ps1` 会建立 `.venv` 并从 Python 软件源安装依赖；安装依赖需要联网，素材库运行本身不依赖云服务。也可由公司 IT 提供内部软件源或离线 wheel 包。

服务关闭、设备关机或休眠后无法访问。第一版没有注册开机自启；建议使用固定内网 IP 的常开专用设备。

`start.ps1` 会把服务作为子进程运行并等待，因此按 Ctrl+C 或关闭启动窗口都会同时停止服务，不会留下占用 8750 端口的后台进程。如果仍有残留，可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\stop.ps1`；此脚本会先核对该端口上**每一个**监听进程的命令行是否指向当前项目 `serve.py`，只要有一个属于其他程序就整体放弃，不会结束其他应用。

启动窗口会打印实际使用的数据目录，以及在当前会话中设置过的 `ASSET_ALLOWED_HOSTS`、`ASSET_PUBLIC_ORIGIN`、`ASSET_COOKIE_SECURE`、`ASSET_TRUSTED_PROXIES`、`ASSET_DISABLE_SETUP`。这些环境变量由启动脚本传给服务进程，请设置在启动它的同一个 PowerShell 会话中，例如 `$env:ASSET_DATA_DIR = 'D:\CompanyAssetLibrary'; .\start.ps1`。

### Windows 网络与正式内部使用

- 如本机可访问而其他电脑不能访问，请由 IT 检查 TCP 8750 入站规则，仅对公司专用网络和需要的内网网段放行。本项目不会自动修改防火墙或路由器。
- 当前直接启动提供 HTTP，登录和文件内容在网络中没有 TLS 加密。管理员校验密码通过 JSON 请求体传递，不放入 URL。共享给团队正式使用前，应由 IT 配置内网 HTTPS 反向代理和受信任证书；不要在不可信 Wi-Fi 或公网使用。
- 不配置公网端口映射或内网穿透。员工远程使用通过公司批准的 VPN，并遵循内部访问规则。
- 采用反向代理时，保持请求 Host 与浏览器访问地址一致。配置自定义内网域名需加入 `ASSET_ALLOWED_HOSTS`，例如 `assets.company.internal`；设置 `ASSET_PUBLIC_ORIGIN=https://assets.company.internal` 以匹配浏览器来源并启用 Secure Cookie。也可以显式设置 `ASSET_COOKIE_SECURE=1`。不要无条件信任外部转发头。
- 同机反向代理可设置 `ASSET_TRUSTED_PROXIES=127.0.0.1`，让登录限流识别真实客户端；未设置时不信任转发头。首次初始化仅接受无转发头的本机请求，迁移后可设置 `ASSET_DISABLE_SETUP=1` 完全关闭初始化。配置 `ASSET_PUBLIC_ORIGIN` 后，账号管理优先显示该固定地址，供内网和 VPN 员工使用。
- 权限按账号分级：管理员拥有全部权限；内部账号可读、可下载、可上传和编辑，但没有删除权和账号管理权；外部账号只能登录浏览和下载，拿不到令牌。删除操作（图片入回收站、永久删除、删除分类、删除账号）一律只有管理员可以执行。人员离职时删除其账号即可同时断开登录与令牌。暂不支持 SSO 或按部门隔离；令牌（无论谁创建）都能读取整个图库。

## 独立素材目录

默认目录：`H:\AI本地文档\开发\product-image-library\data`。

```text
data/
  library.sqlite3       产品、图片、账号、令牌哈希和操作记录
  originals/            上传原文件，以图片 ID 命名
  thumbnails/           WebP 预览
  temp/                 上传与打包临时文件
```

数据库只记录文件 ID，不接受任意文件路径。`data` 目录不作为网页静态目录公开。缩略图和原图都需要登录或令牌。

更改数据目录，在启动前设置环境变量：

```powershell
$env:ASSET_DATA_DIR = 'D:\CompanyAssetLibrary'
.\start.ps1
```

不要在运行中手动移动或重命名 `originals`、`thumbnails` 内的文件。当前 `ASSET_DATA_DIR` 同时保存 SQLite 与图片，应使用本机可靠磁盘；暂不直接把 SQLite 放到 SMB/NAS 网络共享。已有文件夹扫描、NAS 素材接入以及数据库与图片根目录分离是后续扩展项，本次未访问或导入公司现有素材。

## 搜索规则

- `001234` 与 `1234` 是不同 SKU。纯数字输入只精确匹配 SKU，查不到时返回空结果。
- `product_code` API 参数也采用精确匹配，适合智能体根据清单取图。
- 普通文字搜索匹配产品名称、SKU、产品别名、图片原文件名及标签；目前为包含匹配，不含语义搜索、拼音或纠错。
- SKU 为字母数字混合且需要唯一确定时，智能体应使用 `product_code`，不要依靠宽泛的 `query`。
- 图片的透明/其他背景由上传者标注，系统只自动判断透明像素，未调用 AI 识别；标注为透明但文件不含透明像素会被拒绝，含透明像素的文件自动归为透明。
- 类型与背景选项在此版本收窄为「产品图 / 场景图 / 其他」与「透明 / 其他」，角度新增「仰视」。启动时会自动迁移旧数据：素材图、主图、细节图、包装图 → 产品图；白底 → 其他；其余值保持不变，旧客户端再传旧选项会被拒绝（400）。
- 上传默认值：类型「产品图」、角度「正面」、背景「透明」。默认背景为透明，因此不含透明像素的 JPG 或普通 PNG 会提示改选「其他」背景，或者先另存为带透明通道的 PNG / WebP 再上传。

## AI / MCP 接入

在网页「AI 取图」中创建只读令牌。完整令牌只显示一次，服务端仅保存其哈希。

在支持本地 stdio MCP 的客户端中配置如下结构。不同客户端的入口和配置格式可能有差异，此处为常见 JSON 形式：

```json
{
  "mcpServers": {
    "product-image-library": {
      "command": "H:/AI本地文档/开发/product-image-library/.venv/Scripts/python.exe",
      "args": ["H:/AI本地文档/开发/product-image-library/mcp_bridge.py"],
      "env": {
        "ASSET_SERVER_URL": "http://127.0.0.1:8750",
        "ASSET_API_TOKEN": "在这里填写网页创建的只读令牌",
        "ASSET_EXPORT_DIR": "H:/AI本地文档/开发/product-image-library/exports"
      }
    }
  }
}
```

如果智能体在其他员工电脑运行，需要把 Python 和脚本放到那台电脑，安装依赖，并把 `ASSET_SERVER_URL` 改为服务器的内网地址。`ASSET_EXPORT_DIR` 始终是运行 MCP 工具的电脑上的目录，不是服务器端目录。

支持的工具：

| 工具 | 功能 |
| --- | --- |
| `search_products(query, limit, offset)` | 查询 SKU、名称或别名，返回产品文字信息 |
| `search_images(product_code, query, kind, angle, background, min_width, limit, offset)` | 查询图片，返回图片 ID 和文字属性 |
| `get_image_info(image_id)` | 核对格式、尺寸、产品归属 |
| `export_images(image_ids)` | 一次下载最多 30 张原图到预设目录，不覆盖已有文件 |

示例指令：

> 找产品 SKU 001234 的透明底正面图，宽度至少 2000 像素，保存到取图工具预设的输出目录。没有符合条件的图片就报告缺失，不替换成相似产品。

### 数据边界

图库服务不调用外部模型、云存储、分析服务或 CDN。网页字体、脚本、图标和样式都在本地。

MCP 适配器不返回图片像素、Base64 或图片内容块；下载在本机进行，返回文件名和保存状态。但是搜索指令、产品 SKU、名称、标签、原文件名和工具文字结果可能被智能体客户端发送给云端模型。如果这些信息也不能外发，需使用公司内网模型，并限制智能体的其他文件读取、截图与外发工具。

本项目提供了 MCP 服务和配置示例，未自动修改任何现有智能体的配置或创建生产令牌。

## HTTP API

接口文档：登录后打开 `/api/openapi.json`。

外部工具使用请求头 `Authorization: Bearer <只读令牌>`。令牌不要放在 URL 中。

常用接口：

```text
GET  /api/products?q=001234
GET  /api/images?product_code=001234&background=透明&angle=正面&min_width=2000
GET  /api/images/{image_id}
GET  /api/images/{image_id}/file
GET  /api/images/{image_id}/file?variant=thumbnail
GET  /api/accounts                   账号列表（管理员）
POST /api/accounts                  {"username":"...","password":"...","role":"staff|external"} 创建账号（管理员）
PUT  /api/accounts/{id}             {"password":"..."} 重置密码并强制该账号重新登录（管理员）
DELETE /api/accounts/{id}           删除账号，同时作废其令牌和会话（管理员）
POST /api/images/delete              {"image_ids": ["回收站中的图片ID"]}
POST /api/export                     {"image_ids": ["图片ID"]}
```

管理员网页通过登录 Cookie 使用新建产品、上传、修改、回收站和令牌管理接口。客户端不应直接读写数据库。

`POST /api/images/delete` 要求图片已先移入回收站（未在回收站的图片返回 409），单次最多 100 张；数据库会在同一事务内移除图片记录并保存文件清理任务，然后清理原图与缩略图。如果文件占用导致清理未完成，响应中的 `cleanup_pending` 会提示待处理数量；任务保存在数据库中，每分钟及重启后自动重试。已永久删除的图片不能再恢复。只读令牌及访客账号无权调用。

## 备份与维护

旧版本机 AI 批量新建功能已移除。启动升级或恢复旧备份时会清理旧写入授权、凭据文件及批次记录；已创建的产品、图片和操作记录保留。AI 取图的只读 MCP 工具继续使用。

备份工具通过 SQLite 在线备份 API 获得一致的索引快照，再复制全部关联图片（含回收站），并逐张校验原图 SHA-256。备份与永久删除、后台文件清理使用跨进程锁，避免复制中的文件被清理。只有目录内存在 `backup.json` 才表示本次备份完成；失败产生的不完整目录不可用于恢复。备份包含账号及令牌哈希，请放在受控位置；至少保留一份与常用设备隔离的副本。

```powershell
.\.venv\Scripts\python.exe manage.py backup 'D:\AssetBackups\2026-10-28'
```

目标必须是新目录，不能位于 `data` 内。请使用实际存在的备份盘；示例不会自动执行。

恢复时先停止服务，把备份目录作为新的 `ASSET_DATA_DIR` 启动，核对产品数量、图片预览和原图下载后再切换团队入口。不要覆盖仍在运行的数据库文件。

忘记密码时，具有服务器本机文件权限的维护人员可以运行：

```powershell
.\.venv\Scripts\python.exe manage.py reset-password
```

交互输入新密码后，所有登录会话和只读令牌都会撤销。可再次在网页生成令牌。

## 产品目录分页

产品目录默认每页 20 个产品，可切换为每页 50 或 100 个。底部显示符合搜索、分类条件的产品总数、当前显示范围及页码，支持上一页、下一页和输入页码直接跳转；超过 200 个产品时可继续翻页查看。

搜索、切换分类、清除分类筛选和切换每页数量会回到第一页。刷新、编辑或关联图片后保留当前页；新建产品后回到第一页。如果编辑或筛选变化使原来的页码超出结果范围，自动加载最后一个有效页。排序沿用原有规则：搜索精确 SKU 优先，其余按创建时间从新到旧，同一时间按产品 ID 保持固定顺序。管理员和访客均可分页浏览，管理操作仍仅向管理员开放。

## 产品目录批量关联图片

管理员在「产品目录」找到产品，点击该行的「去关联」，从待整理图片中勾选，再点击「确认关联」。支持按文件名搜索（包括含数字 SKU 的文件名）、按类型/角度/背景筛选、全选本页及跨页选择，单批最多 100 张。切换筛选也会保留已选图片，可用「清空选择」重新开始。关联成功后自动刷新产品图片数量和待整理数量。

当前只展示未关联产品且不在回收站的图片。提交时会再次检查全部图片：如部分图片已被其他管理员关联到别的产品、删除或放入回收站，整批不修改，并提示重新选择。同一批重复提交给同一个产品不会重复计数。操作只更新产品归属，原图、缩略图、类型、角度、背景和标签保持不变。

接口 `POST /api/products/{产品ID}/images/associate`，JSON 请求体为 `{"image_ids":["图片ID", "图片ID"]}`，仅限管理员会话。访客和只读令牌均无权调用。查询待整理图片时，可使用 `GET /api/images?unassigned=true&filename=001234`；`filename` 独立于原有 SKU 精确搜索规则。

## 产品分类

管理员在「产品目录 → 管理分类」中可以查看每个分类的产品和图片数量，并删除分类。删除前会展示受影响的产品、有效图片及回收站图片数量；确认后在同一个数据库事务中完成：

- 删除分类选项，该分类下所有产品保留并改为“未分类”。
- 解除这些产品与全部图片的关联，有效图片回到“待整理”。
- 回收站图片也解除产品关联，仍保留回收站状态，恢复后作为待整理图片。
- 原图、缩略图、图片标签等属性保留；其他分类的产品和图片不受影响。

这项操作会清除原来的分类和图片归属，恢复时需重新分类、关联。只允许管理员会话操作，访客和只读令牌无权删除分类。确认期间关联范围发生变化会返回 409，页面更新影响数量后需要再次确认。新建、编辑产品会在写入事务内重新检查分类，避免并发写入已删除的分类。

相关接口：`GET /api/categories/manage`、`GET /api/categories/deletion-preview?name=分类名`、`DELETE /api/categories`。删除请求体为 `{"name":"分类名","preview_token":"预览返回的校验值"}`，分类名允许包含斜线等字符，不放在 URL 路径中。

产品 SKU 对应接口中的 `code` / `product_code` 字段，已有接口参数保持兼容。产品分类为单选，可以保留“未分类”；点击“新增分类”可创建共用选项。已有产品的分类在启动时自动加入选项列表。

品牌字段已从接口和网页下线：新建、修改产品的请求中即使带有 `brand` 也会被忽略，搜索与 `/api/overview` 不再返回品牌。数据库中的历史品牌值原样保留，未做迁移，需要时可由维护人员直接查询数据库。
