01

创建访问令牌

为每个工具单独创建令牌，可随时撤销。管理员可授权查询下载，或单独授权新建产品、关联图片；内部账号的令牌可查询、下载和上传。外部账号不能创建令牌。

请保存这个令牌，仅显示一次
02

连接本地智能体

下载 MCP 工具 mcp_bridge.py。在支持本地 MCP 的智能体中配置 Python 启动命令和环境变量。

ASSET_SERVER_URL=
ASSET_API_TOKEN=查询下载令牌
ASSET_WRITE_API_TOKEN=管理员签发的新建产品令牌
ASSET_ASSOCIATE_API_TOKEN=管理员签发的图片关联令牌
ASSET_SITES_TOKEN=站点服务访问令牌
ASSET_EXPORT_DIR=本机素材输出目录

仅需取图时可不配置写入令牌。私有站点还需要 Sites 平台的服务访问凭据。调用 create_product 时提供产品 SKU、名称、可选的已有分类和别名；重复 SKU 会报错。调用 associate_images 时提供 product_sku 和 image_ids；每批最多 100 张，已有其他产品归属时整批拒绝。Codex 可下载 管理员授权脚本，在本机输入管理员账号完成授权；关联图片使用参数 --scope images:associate。 接口文档：OpenAPI JSON ↗

取图工具不会主动把图片像素发给模型；SKU、名称和工具返回的文字可能进入云端模型上下文。若所有资料均不得外发，请连接公司内网模型，并限制其他文件读取工具。

01

访问地址

邀请同事访问这个云端地址，通过站点验证后，用各自的素材库账号登录。

站点目前仅你可访问。向同事开放时，还需在 Sites 设置中授予相应访问权限。

02

新建账号

内部账号可以上传素材并通过 AI 取图下载；外部账号只能登录浏览和下载，不能上传、修改，也不能创建令牌。

03

账号列表
